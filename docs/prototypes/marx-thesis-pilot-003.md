# Pilot 003 — マルクスを「解釈し直せ」と逆転させたジジェク

**状態:** 2026-11-20にローカルで書き出し・デコード確認した**91.61秒の日本語ショート試作**（本人評価未了、未公開）。元の英語動画を切り抜いた作品ではない。Pilot 001/002のユーザー不採用を受けて、概念説明アニメを廃止。映像はジジェクが話す**2013年の別講演**、ナレーションは新規の日本語合成音声。8つの論点／24字幕チャンク。

## 学べる主張
マルクス第11テーゼ（世界を解釈するだけでなく変革せよ）→ジジェクの「20世紀は行動しすぎた」→第一次世界大戦・十月革命・スターリン体制という講演内の具体例→ヘーゲル的な解放から恐怖への反転→この観点をAIへの楽観論にも適用→ジジェクの「再び解釈する時が来た」という逆説。演出のために架空の休日アプリや寸劇を追加しない。
