# Design acceptance
入口=作品の表紙、動画棚=元動画の認識、探索=各部屋、本文=読みやすい出版物。個人教材はローカル専用。
- 色: editorial.css の paper/ink/mute/hair/accent/surface/hover が正本。注釈は world-rooms.css の language/context トークン。下線・背景・罫線で区別。状態は aria-current/pressed と文字・形を併用。
- 欧文見出し Newsreader、UI Plus Jakarta Sans、日本語 Noto Sans JP、代替 Georgia/sans-serif。部屋見出し30–54px、スマホ26–30px、UI12–14pxを目安にし、本文は既存の文字サイズ設定を尊重。注釈は原文直後、訳は下部ドックまたは本文。
- 余白: 小画面14–18px、PC24–48pxを目安。部屋の絵と情報を境界線で分け、本文は紙面・罫線優先。控えめな角と影。UI・文字は生成画像に焼き込まない。
- トップは横長の元動画サムネイル、書庫は独自表紙、本文は元動画。ロゴ mark.svg、6ジャンルは判別可能なベクター紋章。
- 美的合格基準: 独自性、構図、統一、人格、機能との融合を各0–2点、8/10以上かつ0点なしを改善目標（所有者評価が優先）。技術合格は別。320pxで溢れない、既存資料・章・注釈・和訳・動画・個人データを保つ。低モーションでも使える。
- 比較は同じviewport/theme。オフライン検査は実回線や外部動画を保証しない。生成モックアップを実画面とみなさない。
