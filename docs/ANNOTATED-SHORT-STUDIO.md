# Annotated Shorts Studio v2 — Pilot 013 production baseline

2026-11-24 本人の評価「めっちゃいいね」。42.97秒の Pilot 013 のデザイン言語（暗色の引用／紙色の編者註、金・深緑、肖像の緩いズーム、日英対応字幕、史実の対比・時間軸、独自音楽）を汎用化する。これは作品の好評価であり、個別演出の因果効果・全作品の合格・公開承認ではない。旧v1は既存制作との互換用に残す。

## 制作エージェントの実行契約
1. `npm run short:discover -- <slug>` で現行章JSONから候補を発掘。実発言と注釈、前後の段落を読む。候補スコアは編集判断でない。問い・逆説・具体的帰結のうち、視聴者が知りたい論点、原典で回収できる結末、註釈が追加する知識を選ぶ。抽象的な哲学一般、誤解を誘う切り抜き、発言の留保の削除を避ける。
2. `templates/annotated-short/studio-brief.example.json` を制作ディレクトリの brief.json にコピー。異なる仕組みの引用フック2〜3個を選び、共通本編と回収を固定する。必要な原典の範囲、原文・対訳・注釈・資料の出所を調べる。引用は章ID・発話ID・元時刻を保持。例は未公開の設計用で素材は入っていない。原典録音の照合・利用条件の確認が別途必要。
3. `studio-catalog.json` のパターンから意味に合うものを選ぶ。肖像・史料は出典、年次、権利を別途確認。対比・年表の情報は短く具体的に。引用の間は英日だけ、編者の間は日本語だけ。資料がなければタイポグラフィにするが、関係のない装飾アニメで埋めない。話者の肖像は実録と誤認させない。
4. 音声は原典の録音を適法に利用できれば優先。合成時は同じ役割声で、本人音声でないことを表示。発話時刻は TTS境界、原典時刻、実聴確認または波形確認済みの trim/cuts を記録する（segment.timing.mode=measured、秒は音源内絶対時刻）。別法は1意味句ごとに音源を用意する cue-audio。文字数按分は使わない。波形推定は逐語境界の証明ではない。声の途中の無音を捨てたり切断したりしない。
5. `npm run short:studio:check -- <brief.json>` → `npm run short:studio:plan -- <brief.json>` → 素材調達後 `npm run short:studio:check -- <brief.json> --media` → `npm run short:studio:render -- <brief.json> --all`。Python Pillow, numpy, pydub, FFmpeg、Noto Sans/Serif CJK、DejaVuを使用。出力は hook ごとの output/<hookId>/ に隔離。MP4、字幕SRT、タイムライン、全字幕画面のcontact sheet、声・音楽単独・最終ミックス。選択版だけなら --all を省く。媒体の操作UIと実機可読性、聞き取り、註の密度、フックの約束と回収を人間が審査。機械検証は人間の良否・権利確認ではない。
6. `npm run short:studio:check -- <brief.json> --publish` は追加の権利・本人承認ゲート。ここでは自動投稿しない。
7. 公開後の実測は `metrics.example.json` を参考に実値だけ入力し、`npm run short:metrics -- <observations.json>` で同じプラットフォーム/本編版/期間のフックを比較。24h/72h/7d の固定窓、フィード表示・視聴選択率・engaged views・平均視聴割合・完了率・離脱時刻を取得できる範囲で残す。未取得は null。単なるview差は因果効果としない。配信先のデータ連携は別工程であり、API取得・自動改善は未実装。離脱位置をタイムラインと照合し、次の版で変更する工程を一つ決め、原典とデザイン基準を維持する。

## 品質チェック
- 0秒で誰の何の発言か分かる。フック後に短い出典説明。本文・編者註・引用への復帰。
- 出典を確認済みと偽装しない。引用は正本の発話文字列と一致。時刻は発話単位で、未照合の音源は合成と明示。
- 字幕は最大英2行・日2行、編者のみ日最大4行。禁止行頭句読点を回避。720×1280の安全域は暫定（実アプリで確認）。
- 独自のコード生成音楽2種、効果音3種。音量測定、過大ピーク防止。端末試聴は必須。
- 同じ原典でもフック以外は同条件で比較。人間の評価なしに自動採用しない。
