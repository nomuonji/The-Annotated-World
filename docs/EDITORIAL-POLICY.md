# The Annotated World — 発信コンテンツ編集方針 v0.1

Status: 編集方針の検討版（公開承認ではない）。Pilot 001・002ともに本人不採用。日本語ショート制作は [日本語圏の再生実績研究](research/2026-11-20-japanese-short-form.md) を先に参照する。 [ヒット動画研究](research/2026-11-20-knowledge-video-formats.md) を参照し、動画本体の実観測を経て演出を再設計する。

## 編集の約束
海外の思想・知識・文化を通して、世界の見え方を変える。英語学習は面白い原典を読む・聞く過程の副産物。語彙解説、試験対策、名言転載、字幕だけの切り抜きを主役にしない。The Annotated World の原典資料を入口と出口にしつつ、独自の問いと解釈を持った完結する作品を作る。
想定読者は思想・文化に関心がある日本語圏の人と、原語にも触れたい読者。現段階では読者モデル・集客実績は未検証。既存の消費者モデルに直接該当するものがないため、強制適用しない。

## 情報密度を最優先する編集原則
- 教材の実際の論証（出典・背景・固有名詞・対立・反例）を、抽象的な説明用アニメーションや創作寸劇に薄めて置き換えない。60〜120秒の場合も実情報と具体的な検討の連鎖が必要。視覚は当事者の表情・一次文献・史料・図表など理解・検証に資するものを選ぶ。知識が増えない画面や間は削除。
- 日本語ショートは日本語の自然な話し方、短い字幕チャンク、発言主体・固有の題材、冒頭の疑問/意外な論点から設計する。日本語ナレーションなしの資料スライド、汎用の英語合成音声、情報の薄い象徴アニメを作らない。
- 完全対訳教材は章と発話を構造的に残す。短尺化では対象論点を明確に区切って抜粋し、見せた部分だけで原典全体を代表させず、何を省いたかを制作者が把握する。細部が重要な議論は長尺を選ぶ。
- 別時期のCC講演映像を使用する場合、どの時点で撮影されたかを常時表示し、その時点の音声と新たな引用を混同しない。原講演を録画したふりをしない。

## 企画判定
1. 原典を読んで、常識を覆す視点、見過ごされる矛盾、意外な概念、作品の新解釈、思想上の対立を選ぶ。
2. 一つの企画につき一つの問い・一つの発見。視聴者が具体的に何を見るか、見終わった時に何を理解するかを明記する。知識を薄めて釣るのではなく、具体例で入口を作る。
3. 原典の主張、背景知識、制作者の応用・批評、仮想例を分離する。単純化しすぎない。哲学者の発言を一般的事実として断定しない。時事・科学・歴史の事実は別ソースで照合する。
4. 意外性と独立した作品価値がなければ短尺にしない。無関係な素材・画一的な図解・名言連投を避ける。実演やアニメーションで論旨が進む映像を優先する。
5. 語学は原語概念、必要な短い原文、日本語字幕を自然に添える。語彙学習の説明を無理に入れない。翻訳は意味・文脈・皮肉・限定を守る。

## シリーズ
- 思想で読み解く日常：具体的な矛盾 → 概念 → 別の見え方。
- 哲学者の映画批評：作品の観察 → 解釈 → 読み直し。映画素材の権利は別確認。
- 知の対立：同じ問いに対する複数の立場 → 違いの理由 → 未解決点。
- 海外知識人の視点：原典の議論・独自の問い → 背景 → 批評。
- 一つの概念：定義だけではなく、何を説明できるのかを示す。

## 映像引用・出所
原典映像は論拠として必要な範囲でのみ利用を検討する。単なる翻訳・切り抜き・見どころ集ではない。引用の可否は著作権法32条・48条等の条件を個別に検討し、適法な引用の翻訳は47条の6の規定を確認する。固定秒数で許容判定しない。出典を画面/説明に示し、引用と独自解説を区別し、発言の趣旨を保つ。映像が必要でなければ自作図や要約、公式埋め込み・時刻リンクに切り替える。素材入手方法の規約適合性、配信先規約、収益化審査、必要な各権利を別々に確認する。法的結論は事例ごと、必要に応じ専門家・権利者へ相談。原典映像が未確認の場合はクリップ範囲や発音を捏造せず、引用候補は保留。公開・配信は別のユーザー指示が必要。

## 日本語ショートの必須ゲート
- 実在する日本語ヒットショート3本以上と同チャンネルの不発例を、動画・音声・字幕の実物で観測してから制作する。メタデータだけなら観測済みと書かない。
- 話者のリアルな声/姿、具体物、予想を外すエピソード、自然な口語字幕を優先し、概念の説明用アニメ・全画面スライドを既定形式としない。
- 以前の2本（全画面スライドと休日の2Dアニメ）はユーザーに不採用。参考テンプレとして再利用しない。

## 制作契約
- 教材ID、章/発話アンカー、原典URL、時刻候補、原典確認状況、外部裏付け、用途・独自論旨、引用理由・範囲・取得方法、代替映像、媒体別の成果物を制作ブリーフに記録する。
- 素材・フック（本編と異なる仕組みの候補を複数）・視覚的な変化を決めてから台本。原典未確認の企画は本番素材を確定しない。既存の動画制作基盤を変更せず、制作する場合は担当レポの実行契約に従う。
- 縦型の初期目安30〜60秒、内容が必要なら長く。長尺は論点に合わせて設計。ロゴや挨拶から始めず、最初の画で問いが分かるようにする。
- 権利確認状況、技術検証、編集品質、視聴実績を分ける。試作は公開用完成品として扱わない。
- 同じ教材から派生する場合も、動画は独立した問い、テキストは論点、図解は関係性に絞り、同じ内容の機械的な再投稿をしない。
- 工数を増やす前に、公開承認後の視聴維持、保存・共有、サイト遷移、再訪を媒体別に測る。再生数や来訪を事前に保証しない。リンクは該当章・原典へつなぐ。サイトの公開URLが未確定なら捏造しない。
