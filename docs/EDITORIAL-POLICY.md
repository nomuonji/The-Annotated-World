# The Annotated World — 発信コンテンツ編集方針 v1.0

Status: **交互引用・編者註の短編制作型はPilot 012を暫定採用基準に確定（2026-11-20）**。作品ごとの公開・権利審査は未承認。Pilot 001・002ともに本人不採用。日本語ショート制作は [日本語圏の再生実績研究](research/2026-11-20-japanese-short-form.md) を先に参照する。 [ヒット動画研究](research/2026-11-20-knowledge-video-formats.md) を参照し、動画本体の実観測を経て演出を再設計する。

## 編集の約束
海外の思想・知識・文化を通して、世界の見え方を変える。英語学習は面白い原典を読む・聞く過程の副産物。語彙解説、試験対策、名言転載、字幕だけの切り抜きを主役にしない。The Annotated World の原典資料を入口と出口にしつつ、独自の問いと解釈を持った完結する作品を作る。
想定読者は思想・文化に関心がある日本語圏の人と、原語にも触れたい読者。現段階では読者モデル・集客実績は未検証。既存の消費者モデルに直接該当するものがないため、強制適用しない。

## 情報密度を最優先する編集原則
- 教材の実際の論証（出典・背景・固有名詞・対立・反例）を、抽象的な説明用アニメーションや創作寸劇に薄めて置き換えない。60〜120秒の場合も実情報と具体的な検討の連鎖が必要。視覚は当事者の表情・一次文献・史料・図表など理解・検証に資するものを選ぶ。知識が増えない画面や間は削除。
- 2026-11-20更新：このシリーズのショートでは、英語音声を主体にし、英語と日本語のバイリンガル字幕を常時併記する。英語の原典フレーズ、正確な日本語訳、思想の論証を同時に追えること。原典本人の音声が利用できない場合は、本人の声を模倣せず、独立した英語ナレーションを合成音声と明示する。字幕は発話ごとに短く切り、長文を何秒も画面に固定しない。
- 完全対訳教材は章と発話を構造的に残す。短尺化では対象論点を明確に区切って抜粋し、見せた部分だけで原典全体を代表させず、何を省いたかを制作者が把握する。細部が重要な議論は長尺を選ぶ。
- 別時期のCC講演映像を使用する場合、どの時点で撮影されたかを常時表示し、その時点の音声と新たな引用を混同しない。原講演を録画したふりをしない。

## 受理された編集改善 — 英語の速度と語句対応（2026-11-20）
- 第5版は「だいぶ良くなった」と評価された。次版は英語の自然な聞き取り速度を優先する。声の速度設定は+24%から+6%に変更したが、数字を全番組の固定規則とはしない。リズムは発話・情報の提示順序と自然な短い間で作る。
- 文章からの要約時に原典の留保、逆説、辛辣なジョーク、本人が留保した立場との距離感を落とさない。出典本文に根拠のない拡張をしない。原典を単なる名言集やポジティブな説教に置き換えない。
- 英語音声+英日併記字幕を維持し、鍵になる英語の部分文字列と対応する日本語の部分文字列を同色で同時に表示し、視覚的にも対応を結ぶ。英語の聞き取り中に、訳の対応箇所を識別できること。強調語は各発話の論旨から選び、数合わせや装飾目的の色付けをしない。
- 合成音声は必ず合成音声と記載。本人の実音声のように装わない。別年次の肖像や史料も実際の講演映像として見せない。未照合の原文の逐語性・話者ニュアンスを検証済みと書かない。
- [Pilot 006：英語音声と17組の日英連動ハイライト](prototypes/zizek-marx-v6-linked-bilingual.md)。映像技術合格とユーザー採用・視聴維持の確認は区別する。

## クロスプラットフォーム字幕と音による引き（2026-11-20更新）
- [Pilot 007](prototypes/zizek-marx-v7-audio-safezone.md) では字幕の中心を上げた。720×1280の編集用目安は横74–542px、高さ192–834px、字幕は506–827px。プラットフォーム共通の保証ではなく、公開前に各アプリのプレビューで右端と下端のUI被りを検査する。
- リテンションの引きは元の論証に含まれる対立・皮肉・歴史の逆転・後半の問いから作る。字幕だけでなく、最初の一画と発話の第一声を合わせる。情報を希薄化したアニメ、無関係な画像、無意味なハイテンポ切り替えは禁止。
- 音響：英語の可聴性を第一に、原則として音声と素材を分けて仕上げる。BGMは小さく敷き、話し声の間はダッキング。元の発言の温度感・意外な展開にのみ短い効果音や音量変化を付ける。BGMやSEの著作権・ライセンスを確認する。今回のコード製オリジナル音は第三者音源を使用していない。
- 出力検査：字幕の描画位置、合成音声と日英字幕の同期、音量（LUFS/true peak）、音声と映像の再生、主観的な聴取、各アプリの見え方を区別する。視聴維持・バズの改善は実測まで主張しない。

## Pilot 008 の直接フィードバックに基づく修正（2026-11-20）
- ユーザーの直接FB「BGM聞こえない。字幕が読みづらい。スペースがやたら開いててもったいない」。BGMには聴き取れる音量と中音域の実際のリズム／旋律を確保する。音声との音量差だけでなく、BGM単独と完成mixの双方を計測し、可能なら実耳試聴する。今回はBGM RMSを約−41.9→−29.7dBFSに改善した。
- UIに被らないことだけを目指すと文字が細く・折り返しが多く・画面下に巨大な無情報領域ができる。字幕はフォントサイズ、行数、EN↔JA距離、左右幅、下端、写真が見える領域を同時に調整する。今回の720×1280試作では英日36〜38px、左揃え、横x44〜596px、カード下端997pxを使用。これは確定的なプラットフォーム共通安全領域ではない。
- より大きな字幕で17組の日英色連動ハイライトを維持し、英語音声の速度と思想の情報密度を変更しない。実機UI・人間の聴取と視認性評価は、生成／コード上の検査と別に扱う。

## 視認性と画面構成：Pilot 008の反例研究
- 直近の第8版の画面は長文字幕を英語最大5行＋日本語最大3行で固定し、さらに上部ラベル＋7か所の大見出しを重ねていた。研究上の原因はフォントの小ささではなく**三重の文字階層とほぼ静止する画面**。
- 詳細な実測、比較、学術出典、媒体別UIと次に試す2デザインは[見た目と構成の再研究](research/2026-11-20-v8-composition-visual-audit.md)を正本とする。**第9版はこのリサーチ時点で未レンダー**。元の英語音声・英日語句対応・情報密度・ニュアンスを削らず、字幕を意味句ごとに再編する。
- 同じ画面で同時に多くの長文を読ませず、中心となる写真・史料を最大限見せる。人物・史料・比較を別モードで構成する。英日字幕の上下は学習効果が文脈・言語・目的で異なるため、ユーザー評価と実測により選ぶ。
- 広告向け安全領域を通常投稿にも一律適用したり、どの媒体でもUIに重ならない保証をしたりしない。媒体ごとに確認する。

## Pilot 009：字幕を読むための視覚設計（2026-11-20）
- [Pilot 009：意味句単位の日英字幕と写真の構成](prototypes/zizek-marx-v9-semantic-visual-hierarchy.md) で以前の読みにくさを修正。長い字幕を常時大量表示するのではなく、20ビートを40の意味句へ分割して原稿全文を保持。同時表示は英語1〜2行、日本語1〜2行を目安とし、英日17箇所は同色で対応させる。
- 「話者」では原典の人物の表情、「史料」では出典と現物、「比較」では論証上の対立を主画面として提示する。常設の大見出し・大きな文字パネル・意味のないブランド帯を競合させない。
- 音声の実際の語句タイミングに合わせるのが最終品質条件。現プロトタイプではビート長に按分した段階なので、単語単位の厳密な同期は未検証とする。実耳による視聴・アプリのUIチェック・視聴者の離脱は別途確認。

## Pilot 010：原典の発言が主、解説は註（2026-11-20の最新指示）
- ユーザーの直接フィードバック：「もっとジジェクの言葉がメインでそこに註釈のように細く解説を差し込んでいくという方がいい。今はわれわれの言葉がメインになっていて主従が逆」。以後このシリーズでは、まず**原典の話者自身の発言・言葉遣いを編集の背骨**にし、編集者の説明英文を延々読み上げない。
- [Pilot 010](prototypes/zizek-v10-quote-first-annotations.md) では13の原文抜粋の英語読み上げを主役に変更し、解説は必要時の小さな日本語の「註」（音声なし）。英文を先に見せ、自然な日本語訳と対応表現の色付きハイライトを添える。写真・歴史史料は原文の内容に対応させる。
- 話者の特徴的な留保・ジョーク・評価の複雑さ・言い直しは作品価値であり、不要に丸めない。話者と編集者の意見を見分けられること。引用を並び替えた際は、原講演の連続音声であると装わず出所と引用範囲を明示する。
- 実音声がなければ合成音声の「原文読み上げ」として明示。本人の声色を模倣しない。長い引用比率について公開時の著作権上の独立性・必要性を個別審査し、権利確認前は投稿しない。

## 引用と註釈の共存・著者明示・音響（2026-11-20）
- [Pilot 011](prototypes/zizek-v11-speaker-annotations-audio.md) に直接FBの失敗と検査を記録。原文引用は作者の氏名・肖像・出典時刻によって**全画面で発言者を明確にする**。合成音声は「本人の声ではない」と表示し、チャンネルの発言に見せない。
- The Annotated Worldの**註は分析上の情報追加**であり、単なる用語名・一言ラベル・引用の言い換えではない。発言の意味を深くする歴史・哲学・言語上の文脈、留保、論点を補う。声は本人の言葉を優先し、註は視覚上別レイヤーにする。13引用ブロックには13の内容ある註を作成。
- BGMが制作担当者の数値上は混入していても、本人に聞こえなければ未解決。完成ミックスと音楽単独を試聴できる状態で提出。第11版ではBGM RMSを−31.83→−26.14 dBFSとし中域も増強（音声より平均約5.75dB下）。これは今後の固定数値でなく比較測定の例。人の試聴評価と技術検証を別にする。
- **単独要素の達成で合格扱いにしない**。引用・話者・註釈・翻訳・音楽・画が総合的に一つの作品として機能することが品質基準。

## 最新の最優先契約：引用と註釈の**時間的な交互編集**（2026-11-20）
- 以前の「引用字幕と註を同時に表示する」Pilot 011の方式は本人に不採用。最新版[第12版](prototypes/zizek-v12-voice-and-commentary-alternation.md)を優先する。フック（著者の意外な一言）→別声の編者ナレーションで出典・日時・場所などを説明→著者の原文引用へ戻る→別声の註釈→原文へ戻る、という明示した順番で設計する。
- **男性引用音声／女性編者註音声を固定し、引用の途中に無関係な性別/エンジンの声が混ざらない**。自動TTS fallbackで声質が変化する区間は不採用。声が切り替わるときは同時に「SLAVOJ ŽIŽEK・原文」「THE ANNOTATED WORLD・編者註」という画面表示を変える。
- 引用場面では英語原文＋日本語字幕だけを見せる。**註釈の説明を同時に表示しない**。註釈場面では日本語編者コメントだけを字幕として段階表示し、別時刻の原文テキストを隠す。読む時間を確保する。編集者の註釈は一般論・名詞ラベルではなく実際の文脈と歴史・哲学的含意を提供する。
- 発言の原典・場面を、フックのすぐあとにナレーションとして言語化する。第三者の参考写真を実際の講演会場・原講演映像と偽装しない。
- BGMを「技術上存在するが聴こえない」状態にしない。中域楽器・リズムのある実際の音楽を、声を隠さない可聴水準に調整し、BGM単独と完成ミックスを両方プレビュー可能にする。第三者楽器サンプルの利用許諾も公開前に確認する。
- 声の主従と引用/注釈の分離、長尺の視聴維持、各プラットフォームのUIを含む評価は、書き出し検証と分離する。ユーザー採用まで未採用の試作として扱う。

## 採用基準型（2026-11-20）：原文→編者註の交互編集
ユーザーのPilot 012への評価は **「まあ合格ラインかな」**。これは新規題材の制作基準を固定する承認であり、完成品質の全項目合格や公表許可ではない。より古いPilot 010/011の方式は下記の基準より優先しない。

- **編集順序を固定**：0秒の話者本人による強い引用フック → 別声の編者による出典・発言の場の説明 → 本人の引用に復帰 → 編者による実質的註釈 → 本人の引用へ戻る。引用間の連続は可。註釈は論点の節目だけで、最後の発言は原典側に戻す。
- **話者の帰属と声**：引用区間は氏名・写真/肖像の出所・実声か合成朗読かの明示、原文と訳。編者区間は「THE ANNOTATED WORLD / 編者註」の識別を伴う別声・日本語字幕のみ。音声エンジンの自動フォールバックによる想定外の声変更は不可。Pilot 012では男性英語引用と女性日本語註を採用したが、他の著者にも機械的に性別を押しつけない。
- **字幕と学習**：QUOTEは英語と日本語訳の短い意味句を1〜2行ずつ、重要な対応箇所は同色強調。CONTEXT/ANNOTATIONでは英語引用を消して日本語註を1〜2行ずつ表示。**原文と編者の補足文を同時に読ませない**。
- **知識密度**：引用本文を主軸とする一方、注釈には時代・歴史的背景・概念・話者の留保・言い回しの温度感など、原文のみでは分かりにくい新情報を含める。分かりきった用語の繰返しやアニメで稼がない。原文引用や再構成には引用範囲と出所を残す。
- **映像/音**：出所のある人物肖像・直接関連する資料・史料を主画面へ。BGMは声の理解を妨げないが**聴こえる**水準、楽器とリズムが存在すること。楽曲・サンプル・SoundFontの公開利用権を別途確認。BGM単独と声込みミックスを試聴し、数値検査と主観評価を分ける。
- **媒体/公開**：スマホ表示の可読性とShorts/TikTok/ReelsのUIを別々に試験。原典の真正性、引用・翻訳・音源・画像の権利、公開承認は制作成功とは別。公開の許可がなければ投稿しない。

## 企画判定
1. 原典を読んで、常識を覆す視点、見過ごされる矛盾、意外な概念、作品の新解釈、思想上の対立を選ぶ。
2. 一つの企画につき一つの問い・一つの発見。視聴者が具体的に何を見るか、見終わった時に何を理解するかを明記する。知識を薄めて釣るのではなく、具体例で入口を作る。
3. 原典の主張、背景知識、制作者の応用・批評、仮想例を分離する。単純化しすぎない。哲学者の発言を一般的事実として断定しない。時事・科学・歴史の事実は別ソースで照合する。
4. 意外性と独立した作品価値がなければ短尺にしない。無関係な素材・画一的な図解・名言連投を避ける。話者本人の適法利用可能な写真・原典に関係する史料や現物の写真を優先し、抽象イメージを描くためだけのアニメーションを避ける。
5. 語学は原語概念、必要な短い原文、日本語字幕を自然に添える。語彙学習の説明を無理に入れない。翻訳は意味・文脈・皮肉・限定を守る。

## シリーズ
- 思想で読み解く日常：具体的な矛盾 → 概念 → 別の見え方。
- 哲学者の映画批評：作品の観察 → 解釈 → 読み直し。映画素材の権利は別確認。
- 知の対立：同じ問いに対する複数の立場 → 違いの理由 → 未解決点。
- 海外知識人の視点：原典の議論・独自の問い → 背景 → 批評。
- 一つの概念：定義だけではなく、何を説明できるのかを示す。

## 映像引用・出所
原典映像は論拠として必要な範囲でのみ利用を検討する。単なる翻訳・切り抜き・見どころ集ではない。引用の可否は著作権法32条・48条等の条件を個別に検討し、適法な引用の翻訳は47条の6の規定を確認する。固定秒数で許容判定しない。出典を画面/説明に示し、引用と独自解説を区別し、発言の趣旨を保つ。映像が必要でなければ自作図や要約、公式埋め込み・時刻リンクに切り替える。素材入手方法の規約適合性、配信先規約、収益化審査、必要な各権利を別々に確認する。法的結論は事例ごと、必要に応じ専門家・権利者へ相談。原典映像が未確認の場合はクリップ範囲や発音を捏造せず、引用候補は保留。公開・配信は別のユーザー指示が必要。

## 日本語ショートの必須ゲート
- 実在する日本語ヒットショート3本以上と同チャンネルの不発例を、動画・音声・字幕の実物で観測してから制作する。メタデータだけなら観測済みと書かない。
- 実際の話者の顔が写る画像と議論に直結する写真・史料、予想を外す具体例、英語主体の音声＋完全な英日字幕を優先し、概念説明アニメ・全画面スライドを既定形式としない。原講演でない写真に現在の発話を同期させたふりをしない。
- 以前の2本（全画面スライドと休日の2Dアニメ）はユーザーに不採用。参考テンプレとして再利用しない。

## 制作契約
- 教材ID、章/発話アンカー、原典URL、時刻候補、原典確認状況、外部裏付け、用途・独自論旨、引用理由・範囲・取得方法、代替映像、媒体別の成果物を制作ブリーフに記録する。
- 素材・フック（本編と異なる仕組みの候補を複数）・視覚的な変化を決めてから台本。原典未確認の企画は本番素材を確定しない。既存の動画制作基盤を変更せず、制作する場合は担当レポの実行契約に従う。
- 縦型の初期目安30〜60秒、内容が必要なら長く。長尺は論点に合わせて設計。ロゴや挨拶から始めず、最初の画で問いが分かるようにする。
- 権利確認状況、技術検証、編集品質、視聴実績を分ける。試作は公開用完成品として扱わない。
- 同じ教材から派生する場合も、動画は独立した問い、テキストは論点、図解は関係性に絞り、同じ内容の機械的な再投稿をしない。
- 工数を増やす前に、公開承認後の視聴維持、保存・共有、サイト遷移、再訪を媒体別に測る。再生数や来訪を事前に保証しない。リンクは該当章・原典へつなぐ。サイトの公開URLが未確定なら捏造しない。
