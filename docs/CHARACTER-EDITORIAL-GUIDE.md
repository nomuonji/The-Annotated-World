# 注釈者と余白の編集ルール
注釈者は、世界のテキストを読むが、自分の欲望に対しては都合のよい解釈を選びがちな架空の編集者。既存のピンク髪、眼鏡、ヘッドホン、うさぎを維持する。肩書や名前は未確定。学者・講演者の代弁者ではない。
- 弱さは具体的な行動として表す（夜食、積読、安心できる結論への執着、通知を確認する習慣）。コーラだけで反復しない。
- うさぎは無言に近い短い突っ込みで、矛盾を示す。読者を見下さない。台詞はHTMLで出し、創作と明示。
- 余白は入口と探索ページの編集枠に限定し、長文・固定動画・和訳の邪魔をしない。
- 新教材の追加時に章を読んで実際の問いを一つ選ぶ。資料ID・章アンカー・表情アセット・創作台詞・問いを marginalia.json に追加する。参照先を確認。原文の代替説明、架空の引用、勝手な人物紹介は不可。
- 表紙は内容からモチーフを決め、文字なしの原画とHTMLを分離する。仮素材の状態は manifest で保持。動画制作にも同じキャラクター設定を参照できる。
- 現行2件は各ch1の内容（選択肢と自由、安堵と哲学者の問い）を参照。How to become free の字幕は未照合候補であるため、直接引用しない。

- 編集号と映像の仕様は [WORLD-MOTION-AND-EDITIONS.md](WORLD-MOTION-AND-EDITIONS.md)。既存3件の創作ログ（夜食・安心できる結論・自分の規則）を別々の矛盾として扱う。編集号の更新時に関連ログと次の章を選定し、原文と創作を混同しない。
