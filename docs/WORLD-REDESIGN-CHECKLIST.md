# The Annotated World — 全面刷新チェックリスト

目的: アニメ作品の世界に入り、自然に英語・思想を読み進める体験。イラストの追加だけで完了としない。
進捗: 7/120（今回の全面刷新の受入項目。旧版で達成した技術検証は下記の既知事項に分離）。
各項目は安定IDで管理し、完了時にチェック・根拠（コミット、画面、CI、評価等）を更新する。未検証・保留・対象外は理由を残し、完了に数えない。P0は設計/リリースの必須ゲート、P1は刷新実装。A→B→C/D/E/F/G/H/I/J（依存順で並行可）→K→L。Lは各工程中も必要分を実施し、最終リリース前に集約する。過剰設計せず、機能追加は必要性・根拠を確認する。
