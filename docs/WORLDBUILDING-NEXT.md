# The Annotated World — 次の世界観設計（提案、未採用）
目的はサイトの装飾追加ではなく、原文を読む行為そのものにフィクション上の意味を与えること。実教材と架空の設定・台詞は混同しない。

## 世界の基本設定
- 夜だけ開く「注釈の資料室」。世界の言葉を収蔵するが、注釈者は自分自身を読み解けない。蔵書・索引・私室は彼女の仕事と生活の痕跡。
- 注釈者は有能で知的だが、自分の欲望だけは都合よく解釈する。うさぎは短い行動や反応で矛盾を暴く。毎回哲学の説明をさせない。
- コーラに限定せず、積読、夜更かし、承認欲求、安心できる結論だけを選ぶ、矛盾を認めないといった生活を継続的に描く。
- 資料室の場所には利用者の目的が対応する。書庫＝読む資料を選ぶ、観測室＝思想の接続、標本室＝語彙、映写室＝発話を聴く、私室＝個人教材。空間名は通常の機能名を置き換えず併記。

## 優先実装候補
1. まずホームの探索場面を一つの空間として再設計。背景と独立した前景・道具の透過素材、各部屋へのリンク、位置関係を統一する。テキストボタンとキーボード代替を残す。
2. ブランド固有の造形体系：星図・注釈記号・蔵書印・真鍮の罫線・手書きの修正痕。素材は透過、小型、繰り返し可能。装飾を全ページに一律適用しない。
3. 教材に連動する「夜の編集記録」。実際の章を読んで、彼女がどの箇所を理解し、どこを避けたかを短い創作として描く。創作と原文解説は明確に分離。反応ポーズ差分は用途単位で生成。
4. サイトに時間を持たせる。季節や追加教材に合わせた更新、数週間単位の小さなエピソード。訪問毎にランダムな文章を作らず編集済みの記録を蓄積。通知・連続ログイン等で強制しない。
5. 部屋同士の移動を小さな2D演出で表現（ページをめくる、カードを引く、フィルムが切り替わる）。画像生成は静止画素材、動きはCSS/SVG/コード。reduced-motion、戻る操作、直接URL、表示速度を守る。
6. 動画制作との世界観共有。サイトとショートに同一のキャラクター、配色、蔵書印、字幕・注釈の造形を適用。教材ページが原典、動画が入口。

## 実装しないもの
強制的なログイン、収集報酬、長い演出、スクロールハイジャック、捏造された思想家の発言、読解中にキャラを頻繁に出すこと。トップの元動画サムネイル・既存読解UI・モバイルを守る。
