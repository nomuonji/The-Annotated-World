# The Annotated World — 世界観増強（継続中）
状態: OPEN。2026-11-26、本人指示により旧刷新工程を閉じ、世界観増強を独立した継続工程へ移行。完成判定をしない。編集記録・創作日記・関連モーションページは不採用。教材と無関係な新規コンテンツで世界観を代替しない。
## 原則
- 英語・思想教材の機能そのものが世界観を伝える。造形、空間、構図、光、素材、文字組み、動きで感じさせる。説明文・キャラの日記・設定集を読ませない。
- トップの元動画サムネイル、検索、固定和訳、動画操作、注釈、個人教材を守る。学習への距離を増やさない。
- キャラクターは案内役として既存の姿・小道具・生活の痕跡を用いる。創作台詞の連載はしない。
- 本文は静かな出版物、探索画面は没入型。各ページで演出密度を調整する。
- 以下は独立した継続工程。既存実装を基準とし、採用は実画面と本人評価に基づく。チェック項目数の達成で美的完成を宣言しない。
## W1 空間と美術
- [ ] 既存PC・スマホの実画面を再レビューし、世界観が途切れる箇所と美術上の弱点を特定。
- [ ] 中国ACG・ゲームの実作品から空間構成、視線誘導、レイヤー、照明、装飾の組み合わせを追加研究し、具体的に転用。
- [ ] 資料室・書庫・観測室・標本室・映写室・個人読書室の視覚的な位置関係と共通モチーフを設計。
- [ ] 探索図をさらに空間的に見せる複数の実寸構図を試作。既存の使いやすさを維持し、必要なら現行図を残す。
- [ ] 場所ごとの空気感・照明・遠景・前景を設計し、配置先を決めてから新規アセットを生成・登録。
## W2 独自のUI造形
- [ ] 書庫の棚・資料票・索引、概念とテーマの関連、語彙標本の表示を用途別にデザインし、単なるカードの繰返しから脱却。
- [ ] 蔵書印、罫線、注釈括弧、章扉、フィルムや紙片などの独自素材を整備。装飾は情報の役割を持たせる。
- [ ] 各下層ページの実際の情報量に合わせた構図を検証。空のジャンルでも不自然にならない。
- [ ] キャラクター・うさぎ・道具の見せ方を、画面の機能と空間の中で深化させる。日記や創作記事は作らない。
## W3 動きと質感
- [ ] 光、影、埃、紙、レイヤーの控えめな環境演出を比較試作。
- [ ] 部屋への移動・検索結果・索引の展開など、操作に意味のある短い動きだけを試作。
- [ ] 実動画クリップの字幕・注釈・紋章・画面構成にブランド造形を活用する試作（創作ログ映像ではなく、実教材の入口）。既存制作パイプラインは維持。
## W4 検証・継続
- [ ] 320/390/768/1440幅・両テーマの実画面比較、読みやすさ、操作性、画像容量とLCP/CLS、reduced-motionを確認。
- [ ] 本人評価を画面単位で記録し、良くない案は戻す。反応・評価未取得を完成としない。
