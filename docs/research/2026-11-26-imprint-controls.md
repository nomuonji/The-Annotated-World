# Imprint — low-level interface grammar
Owner feedback: previous layout-level changes almost indistinguishable; focus on design patterns at the lowest visual layer. This iteration deliberately preserves PR57's composition and all native behavior. It is not another banner redesign.
## Reference observations and synthesis
- https://ak-ui.yyj.moe/en/guide/design-language — independent Arknights-inspired system, distinguishes command typography, semantic signal and restrained geometry. Not official. Use one strong signal per state, not serials/metal frames.
- https://icaruszezen.github.io/endfield-ui/design/components/button/ and /design/references/measurements/ — independent real-site analysis distinguishes solid commands, low-emphasis text and state contrast. Use weight differences at actual pixel size, not identical outlines.
- https://www.4gamer.net/games/367/G036702/20250322013/ — GDC account of graphic signification, consistent visual identity from real elements. Do not copy the game's marks or assets.
## Original primitives
Ink plane (high contrast, paper/light ink inverse across themes), secondary misregistered impression (3px offset, compress on press), rose signal terminal separated from text (36px width; arrow mask). Selection has a filled ink strip and small pointer in the search scope; inactive has no rectangle. Search has its own solid lens silhouette and baseline, corner register, focus impression. A bookmark-like current navigation mark is a location state, not invented inventory. Custom 24×24 SVG masks use 1.5–2.1px stroke and fill contrast, not generic 1px icon packs. Annotation bracket is used only for a linked topic / source excerpt. Native accessibility stays with the original inputs, links, aria-pressed and disabled. 
Reader: mode and control hierarchy rather than all buttons the same. Preserve geometry; remove glyphs in narrow reader widths; no animation except brief primary press/hover and reduced-motion override. 
## Asset and states
public/brand/ink/*.svg original authored vectors, CSS mask currentColor. No external art dependency. Implicit actual states: default, hover, focus-visible, pressed, selected, disabled, theme. No fake meters or decorative numbering. Main action uses visible arrow and text. Search actual filter count. Use actual full-page CI plus control crops; compare to baseline, not self-certify aesthetic result.
