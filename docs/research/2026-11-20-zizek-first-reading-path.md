## その次の枝（公開順を固定するものではない）
1. **ジジェク→ヘーゲル／サルトル**：自由と必要性、占領下の自由。上記講演内の言及から、本人の著作/講演や一次資料へ。引用内容・適用範囲を正確に比較。
2. **ジジェク→ラカン**：欲望、享楽、〈大文字の他者〉。第一弾の `ch2`・`ch9` に戻り、説明を簡略化せず概念の一次資料へ接続。
3. **ジジェク→マルクス／現代の労働**：イデオロギー、商品フェティシズム、労働と「自由」。上記46〜50分の例を接続。Molly Whiteの記事には暗号資産・統治の接点はあるが、元論証で直接接続が確認できる場合に限る。
4. **ジジェク→映画・文化批評**：映画の場面を通じてイデオロギーを読む。Sophie Fiennes `The Pervert's Guide to Ideology` を原典候補とし、映画の映像や脚本の独立した権利確認が必要。紹介する映画をジジェクの言葉に従属させるだけでなく、対照的な解釈も調べる。
5. **ジジェク→異論のある思想家**：ジジェクの主張が十分理解できた後、その問題設定に反論や別の答えを出す人物へ。勝手な賛否の帰属は禁止。

## 調査・制作上のゲート
1. まず第一弾の該当章に遡り、どの発言が次回を要請するか特定する。
2. 原動画・発言者・原文入手元・正しい時刻/英語本文をチェック。第三者自動文字起こしなら個別聞き取り照合必須。
3. 既存の `CONTENT-AGENT.md` に従い、まずYouTubeからの直接字幕または音声取得を成功させて取得証跡を残す。転載可能性は別に確認し、権利不明の長文を公開データへコミットしない。
4. 出典を伴った英語→和訳→本物の理解を促す注釈を制作。原文と編集者の推論を表示上も区別。関連テーマは実証済み接続のみメタデータに登録。
5. `npm run content:inspect`、`content:check`、`check`、`build`、`verify:archive` を実行。教材本文未公開の調査メモはこのページ検証を通過した扱いにしない。
