# 中国ACGの視覚設計から資料室への転用（追加調査）
調査日 2026-11-26。既存の研究を補足し、固有IPの素材・UIをコピーしない。
- Koi He, Arknights 2nd Anniversary Web Design (2021): https://koikoi.me/Arknights-2nd-Anniversary-Web-Design-copy 。制作者が画面と動きの設計を担当し、実装とデザインに差分があると記述。適用: 静止画で構図を決め、動作を別レイヤーで実装し、実スクリーンショットで受入。
- ak-ui independent study: https://ak-ui.yyj.moe/en/guide/official-site-study 。1280/390の実測、日付/分類/タイトルの分離、細い区切り線、二言語の階層、現在位置と番号、縦横画面の並び替え。独立研究であり公式設計規約ではない。適用: 書庫の台帳ラベル、章番号、索引行、現在地の下線。モバイルでは文字を縮めず縦に積む。小さすぎる原典の文字サイズは模倣しない。 
- Bluepoch interview, 2026-08-28: https://www.pockettactics.com/reverse-1999/anniversary-interview 。衣装を人物の生活や物語の一部にし、UI・シーン・人物の共通モチーフを組み合わせると説明。適用: キャラの予定表、編集号、書庫の印、映像を同一モチーフで結び、教材本文から創作を分離。
- 今回の具体的操作: トップは動画棚と探索図の後を章/ジャンルに絞り、索引の反復を除く。書庫は実資料数と章数を台帳として示し、分類と検索を近づける。本文は章番号・時刻・話者・原文・訳・注釈の階層。ホバーとキーボードの状態を併記。長尺読解にはゲーム的なアニメーションを入れない。
制約: 公式サイトの全画面を実機で再測定していない。実装の美的評価・再訪効果は別の検証である。
