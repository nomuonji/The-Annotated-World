スタイルロック：既存入口画像を参照。アニメ調の繊細な線と陰影、深いインク/紫、くすみローズ、真鍮色の光、紙の質感。全画像共通で高密度にしすぎず、画面の機能的な余白を確保。文字・ロゴ・レイアウト・モックアップ・チェックリストを画像に生成しない。各原画の生成後に実画像を個別に検査し、Web用のサイズ・圧縮・クロップに加工する。
