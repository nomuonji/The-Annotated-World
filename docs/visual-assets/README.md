# The Annotated World — Visual asset handoff v1.0

実装担当向け。対象: nomuonji/The-Annotated-World / PR #47（基準 f03c6ec）。このパックは画像・配置仕様を納品するもので、サイトの実装や本番反映を行ったものではない。既存の教材、読解・検索・動画同期・個人データは変更しない。

## 使い方

1. `public/brand/` 以下を同じ相対パスでリポジトリへコピー。既存の入口4画像は現行PRのもの。既存ナビの透過6画像は切り出しを修正した互換パスの置換版。
2. `asset-manifest.json` を正本として、パス・寸法・用途・透明度・状態を確認。`gallery.html` を同じディレクトリのブラウザで開くと一覧を確認できる。
3. `PLACEMENT.md` に従って各ページの構図を実装する。画像に描かれた架空文字や図は装飾であり、説明の根拠にしない。
4. `PRODUCTION-GAPS.md` の仮素材は利用上限を守り、最終合格に数えない。新原画に差し替えてもパス・構図を壊さない設計とする。
5. 実装後に320/390/768/1024/1440px、ライト/ダーク、リンク・機能の回帰を確認。実際のリーダーの読解領域を優先する。

## 構成

- `public/brand/`：既存パス互換の入口と小道具、部屋、透過素材、ジャンル、仮教材表紙
- `asset-manifest.json`：機械可読な全点台帳（SHA-256、寸法、容量、用途）
- `PLACEMENT.md`：ページ別・画面幅別の配置仕様、実装順
- `PRODUCTION-GAPS.md`：未完成の画像と次回の生成指示
- `gallery.html`：実素材のブラウザ一覧
- `source-art/`：再切り出し用の生成原画（実装時に public へコピーしない）

状態は `ready`（技術的に利用可能・美的承認未取得）、`existing`（既存素材の再利用）、`provisional`（仮素材・最終生成待ち）。文字入りのデザインボードそのものは納品画像に含めない。
