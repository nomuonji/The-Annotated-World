# 世界観の季節更新と動画制作
archive-edition.json が編集号の正本。暦・位置情報・訪問履歴から強制的に変更しない。号名、短い日記、背景色調、関連ログIDを手動で更新する。ホームの記録は指定した logIds の順で最大2件を表示し、未指定・不存在の不足分は最新の記録で補う。全記録は独立ページに収蔵する。探索図の光はホバー・フォーカスに短時間だけ反応し、低モーションでは動かさない。既存教材・読解設定は不変。新しいログは marginalia.json の末尾に追加し、根拠章を読んでから制作する。
## 共通ビジュアル仕様
- 紋章: public/brand/archive-seal.svg。夜色 #211a2b、ローズ #f2acc9、真鍮 #c6a47e、紙 #fff1eb、ラベンダー #b6a1cf。Webは既存ライト/ダークトークンを優先。
- 文字: 日本語 Noto Sans JP、欧文見出し Newsreader、UI Plus Jakarta Sans、連番は monospace。映像は字幕を焼き込む場合も本文との役割を分離。注釈は語学=紫、内容=琥珀。
- 立ち絵、うさぎ、紋章を原典や発話者と混同しない。編集記録の映像は創作、講演クリップは原文音声を保持する。既存の Pilot013 実制作パイプラインとは分離し、置換しない。
- 9:16 試作: /marginalia/motion/。editorial-motion.json が台本・秒数・出典章・素材の正本。明示操作で再生、低モーション時は手動場面切替。読み物への通常リンクを維持。
- MP4: npm install / npm run build / npx playwright install chromium / node scripts/render-world-motion.mjs [output.mp4]。ffmpeg必須。CIのworld-audit成果物に収録。無音、720×1280、9秒。これは投稿用完成映像ではなく、編集・ブランド統合試作。公開投稿しない。
