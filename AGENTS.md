# The Annotated World — agent editorial contract

Independent Astro static site. Treat `src/content/lessons/*.json` as the public content source of truth; never edit generated dist output. One file per lesson, stable lower-case hyphenated lesson/chapter/block IDs, no arbitrary renaming or reordering with identity changes. File names should match lesson IDs. Add real source URL, author, category, description, ISO publication date, tags, complete bilingual blocks and useful language/context notes. Separate actual verbatim transcript from paraphrases and editorial analysis; mark omissions and uncertain transcription, never claim completeness without checking. Verify the source, translation and rights before changing draft:false. A rights note must accurately identify the license, authorization or public-domain basis; public repository history itself is public, so do not commit unverified full source texts even as drafts. Personal imports belong in /workspace locally, not Git. The published demo is original, not a lecture. Run npm run check and npm run build. New content must not require modifying routes, layout or application logic. Preserve private workspace state and accessible reading controls. No deployment/SEO operator integration or scheduling unless requested.
