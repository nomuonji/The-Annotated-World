# Editorial contract

The original supplied HTML is the design and organizing source. This project is an independent annotated document archive, not English Notes, a gamified English-learning app, or a generic landing page. Keep the reader's continuous chapter order and adjacent en/ja/note blocks, inline emphasis, metadata and links visible in normal HTML without JavaScript. Default to a white editorial page and restrained site header. Add a new source HTML file to src/content/documents; the loader and route derive the rest. Use unique stable lower-case slugs and actual source materials. Verify transcript and translation quality and publication rights; document unresolved status explicitly; do not claim verified completeness or rights merely based on source text. The owner specifically requested inclusion of the first supplied HTML; it is stored byte-for-byte with unverified rights and transcript accuracy disclosed. Do not infer a blanket authorization to publish other unverified works. Never use generated/demo articles as public substitutes. Run npm run check, npm run build and npm run verify:archive. No deployment or periodic jobs unless requested.
